# Contributing

Thank you for your interest in contributing to `performance-decorator`.

## Development setup

1. Fork the repository and clone your fork.
2. Create a virtual environment and install the package's test dependencies.
3. Create a branch for your change.
4. Make the change and add or update tests.
5. Run the test suite with `PYTHONPATH=src python -m pytest -q`.
6. Open a pull request with a clear description of the change.

## Pull requests

Keep pull requests focused and explain the user-facing behavior they change.
Please preserve backwards compatibility where practical and update the README
when public behavior changes. All contributors are expected to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting issues

Use GitHub Issues to report reproducible bugs or propose improvements. Include
your Python version, a minimal example, and the expected and actual behavior.
